# Dataset sources and model provenance

No dataset, downloaded model, training checkpoint, labels, annotations, or
dataset license was present in this repository at audit time. Therefore no
dataset has been accepted, rejected, trained on, evaluated, or combined.

Do not configure `DISEASE_MODEL_ID` until its model card has been reviewed for:

1. crop and disease label coverage matching Fasalyn's supported taxonomy;
2. license and commercial/deployment permission;
3. source data provenance and train/validation/test split;
4. independent held-out evaluation, including low-confidence behavior; and
5. a version/revision pinned in `DISEASE_MODEL_REVISION`.

Metrics: **NOT EVALUATED**. No values are reported because no verified model or
held-out test data is available in this checkout.
